All 46 public Variables alias one of the 43 same-file primitive Variables. Every Variable records WEB syntax matching its generated CSS custom property.

## Scope and binding policy

- All 87 COLOR, FLOAT, and STRING Variables declare `scopePolicy: "explicit"` and include `scopes`. Primitive scopes are empty so primitives do not appear in property pickers.
- The two TIMING Variables declare `scopePolicy: "figma-native"` and intentionally omit `scopes`. Figma owns the non-configurable TIMING scope readback; creation and validation must not assign to it.
- The six primitive and semantic unitless line-height Variables retain percent reference values (145, 170, and 175), declare `bindingPolicy: "reference-only"`, and use explicit empty scopes.
- Never bind a line-height FLOAT Variable to a Text Style. Figma interprets that numeric binding as pixels. Set the Text Style's line height directly as PERCENT and retain its `font.line-height.*` entry in `tokenPaths` for provenance.

## Conversions and intentional loss

- DTCG sRGB colors map to Figma COLOR values.
- `1rem = 16px`; rem dimensions are converted to numeric px.
- `160ms` maps to TIMING `0.16` seconds.
- Unitless line heights map to reference percentages at value × 100; Text Styles apply those percentages directly rather than binding the FLOAT Variables.
- The full Git fallback stack maps to the representative `Noto Sans JP` in Figma only.
- The connected `Noto Sans JP` family has no exact 600 style. `Text/UI Small/Semibold` and `Text/Body/Semibold` remain unsupported candidates and must not be approximated silently.

Five exact Text Styles are creatable: UI Small Regular/Medium, Body Regular/Bold, and Editor Regular. Contract 0.1.0 creates zero Effect Styles and zero components. Notes' Mincho heading remains a product-specific style outside this common projection.

Figma Variables, Text Styles, or Library Publish must not be performed from this document alone; use the generated mapping at an approved canonical source revision and record the resulting file URL/revision in the HANDOFF.
