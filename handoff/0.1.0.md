## Distribution

Initial distribution is the versioned text bundle at `vendor/fukamu-design-tokens/0.1.0/`. Cycle and Notes must vendor the same complete directory and verify every SHA-256 in `manifest.json`. Do not use an archive, local `file:` dependency, link, floating ref, or CDN.

Registry migration is deferred. If later approved, both products must move together to the same exact package version and update their lockfiles.

CSS import order:

1. shared `css/tokens.css`;
2. product legacy-name mappings;
3. product-owned component/theme overrides.

Public exports are CSS, resolved JSON, ESM, CommonJS, TypeScript declarations, the manifest, and the Figma mapping. Public token values and names are listed in `docs/reference/tokens.md` after generation.

## Product mapping summary

Cycle maps `--ink`, text `--muted`, `--paper`, `--line`, `--line-strong`, `--brand`/`--accent`, action colors, focus, and status colors to the corresponding public tokens. Cycle canvas, domain-state colors, layout, timeline geometry, and overlay shadow remain product-owned. Cycle's legacy `--font-weight-medium: 600` maps to common semibold, not common medium.

Notes maps foreground/card foreground, card/popover, border/input, ring, destructive, and warning roles to public tokens. Its overloaded `--primary` must split into action and graph/accent meanings. Notes warm background/decorative values, link treatment, graph/paper effects, Mincho headings, Canvas geometry, and inactive dark definitions remain product-owned.

Detailed, line-level legacy mappings must be added to each product adoption PR and linked here.

## Change requests and rollback

File missing-token or contract-change requests in `fukamu/design-tokens` with the token meaning, owner, base SHA, affected products, and evidence. Coordinate same-token work through the common owner.

Rollback a product by restoring its prior product mappings and complete prior versioned bundle. Never mix files or hashes from two contract versions. Keep deprecated public tokens until both product adoption records show they are unused.
